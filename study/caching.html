Caching

Caching means keeping a copy of something close by so you do not have to fetch it again. It is one of the biggest reasons the web feels fast.

Where it happens

Caches sit at every layer: your browser, a CDN near you, the server itself. The best request is the one that never has to travel because a cache answered it.

How the browser knows

Responses carry headers that say how long a copy is good for. Cache-Control: max-age=3600 means "keep this an hour".

Cache-Control: public, max-age=3600

Revalidation

When a cached copy expires, the browser can ask "has this changed?" with an ETag. If not, the server replies 304 Not Modified and sends no body, saving the download.

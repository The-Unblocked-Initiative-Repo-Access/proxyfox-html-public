The Command Line

The command line is a text way to run your computer. It feels bare at first, but a handful of commands get you a long way, and it is faster than clicking once you know them.

Moving around

pwd shows where you are, ls lists what is here, cd moves into a folder.

pwd
ls -la
cd projects/website

Files

Make, move, copy, and remove files and folders.

mkdir notes
touch notes/todo.txt
cp todo.txt todo.bak
rm todo.bak

Pipes

The real power: send one command's output into another with |.

cat access.log | grep 404 | wc -l

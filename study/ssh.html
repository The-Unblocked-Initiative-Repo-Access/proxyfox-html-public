Tools

SSH

SSH is how you log into another machine securely over the network and run commands on it as if you were sitting there. It is the standard way to manage servers.

Connecting

Give it a user and a host. The first time, it asks you to trust the server's fingerprint.

ssh ada@server.example.com

Keys

Instead of a password, use a key pair: a private key you keep and a public key you put on the server. More secure and no typing.

ssh-keygen -t ed25519
ssh-copy-id ada@server.example.com

Copying files

scp and rsync move files over the same secure connection.

scp report.pdf ada@server.example.com:/home/ada/
